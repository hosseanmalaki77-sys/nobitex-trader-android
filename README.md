
ربات معامله‌گر نوبیتکس برای اندروید

این پروژه برای ساخت یک برنامه اندرویدی با رابط کاربری فارسی طراحی شده است.

امکانات

- نمایش قیمت ارزهای دیجیتال
- اتصال به API نوبیتکس
- شروع و توقف ربات
- نمایش سود و زیان
- آزمایش با پول مجازی پیش از معاملات واقعی

هشدار

معاملات واقعی فقط پس از تأیید کاربر فعال می‌شوند.
ابتدا برنامه را با پول مجازی آزمایش کنید.
